# Fonts

Both fonts are served from this site, so the page loads nothing from other servers.

- **Fraunces** (headings), copyright 2020 The Fraunces Project Authors, SIL Open Font License 1.1: see `OFL-fraunces.txt`.
- **DM Sans** (text), copyright 2014 The DM Sans Project Authors, SIL Open Font License 1.1: see `OFL-dm-sans.txt`.

The files are the variable "latin" subsets (`fraunces.woff2`, `dm-sans.woff2`). Characters outside basic Latin need the "latin-ext" subsets.
